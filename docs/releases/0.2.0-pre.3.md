# Мика 0.2.0-pre.3

Исправления переписки в Telegram и других чатах.

## Установка

Скачать `Mika_0.2.0-pre.3_x64-setup.exe` ниже и запустить поверх прежней версии. Настройки, память и ключи сохранятся. Установщик не подписан: если SmartScreen предупредит, нажми «Подробнее» → «Выполнить в любом случае».

## Что исправлено

- **Программы из Microsoft Store** (например, Telegram) находятся и запускаются по названию. Если программа уже открыта, Мика выводит её окно вперёд.
- **Сообщения не уходят дважды.** Перед отправкой поле очищается, а тот же текст в то же окно второй раз за 90 секунд не отправляется, пока пользователь сам не попросит повторить.
- **Смайлики на месте.** Текст со смайликами вставляется через буфер обмена, а прежнее содержимое буфера возвращается.
- **Переписка Telegram и Discord** читается распознаванием текста с экрана: эти программы не отдают текст сообщений через UI Automation. Нужен включённый «Экран».
- **Больше шагов без плана:** 14 запросов к модели вместо 8, чтобы открыть чат, написать и проверить хватало одного хода.

## Проверено

Тесты Rust, clippy, проверки интерфейса. С настоящим Telegram не проверено.
