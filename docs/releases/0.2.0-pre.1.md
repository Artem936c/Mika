# Мика 0.2.0-pre.1

Первый публичный пре-релиз. Мика — ИИ-помощник для Windows: островок вверху экрана, чат и голос, аниме-аватар с эмоциями, действия в системе через политику рисков, любой OpenAI-совместимый провайдер.

## Установка

1. Скачать `Mika_0.2.0-pre.1_x64-setup.exe` ниже и запустить. Права администратора не нужны.
   - Установщик не подписан сертификатом, поэтому Windows SmartScreen может предупредить. Нажми «Подробнее» → «Выполнить в любом случае».
   - Контрольная сумма лежит в `SHA256SUMS.txt`.
2. Островок появится вверху основного монитора. Щелчок по нему или Ctrl+Alt+M открывает чат.
3. Первый запуск предложит выбрать провайдера и то, что Мике можно. Модель выбирается кнопкой «Выбрать из списка».

Проверенный набор на [RouterAI](https://routerai.ru) (адрес `https://routerai.ru/api/v1`):

| Задача | Модель |
|---|---|
| Основная и зрение | `google/gemma-4-26b-a4b-it` — дешёвая, хорошо ведёт задачи по плану |
| Поиск по смыслу | `perplexity/pplx-embed-v1-0.6b` |
| Картинки | `black-forest-labs/flux.2-klein-4b` |
| Синтез речи | `google/gemini-3.8-flash-lite-tts`, голос `Kore` |
| Распознавание | `qwen/qwen3-asr-0.6b` |

## Что умеет

- **Чат в островке**, обычное окно со свободным размером, перетаскивание между мониторами, уход за игры и развёрнутые программы.
- **Аватар.** Сгенерированный оригинальный персонаж с десятью эмоциями.
  - Моргает, оглядывается, двигает губами во время речи при любой эмоции.
  - Каждая эмоция начинается движением.
  - Отвечает на клики.
  - Иконка приложения и значок в трее — из её лица, точка на значке показывает состояние.
- **Задачи в несколько шагов**: план, ход задачи в чате, кнопка «Стоп», честный итог.
- **Браузер Мики** в отдельном профиле Edge:
  - открыть, прочитать, нажать, заполнить, выбрать в списке, назад;
  - страницы входа, банков и оплаты, а также страницы с полем пароля не трогает.
- **Окна любых программ**:
  - чтение, нажатие по номеру или подписи, цепочки нажатий, ввод, клавиши;
  - после каждого действия видно, что изменилось.
- **Файлы**: поиск, чтение, запись, перемещение, архивы, корзина. Пакет до 200 действий одним подтверждением.
- **Память** с поиском по смыслу и архив прошлых разговоров.
- **Напоминания, таймеры, задачи по расписанию**, список дел, курсы валют, новости, погода, плеер, Wi-Fi, Bluetooth, яркость.
- **Экран**: вопрос по снимку, текст с картинки, снимок.
- **Голос**:
  - озвучка голосом Windows или провайдера;
  - ввод с микрофона;
  - активационная фраза «Мика» на распознавателе Windows, перебивание.
- **Расширения**: серверы MCP (программа или HTTP с токеном), свои команды, Telegram с подтверждением кнопками.
- **Настройки**: модели выбираются из списка провайдера, с ценой, контекстом и описанием; голоса — из списка.
- **Обновления**: проверка по файлу `latest.json`, установка только по кнопке и только при совпадении контрольной суммы.

## Безопасность

- Каждое действие идёт через политику рисков. Без сохранённого правила Мика спрашивает. Действия высокого риска нельзя разрешить навсегда.
- Ключи провайдеров лежат в «Диспетчере учётных данных» Windows, не в файлах настроек.
- Интернет-инструменты, просмотр экрана и микрофон выключены, пока ты их не включишь.
- Окна и страницы с паролями, входом, банком и оплатой Мика не читает и не трогает.

## Где данные

- Настройки, история, память, напоминания, правила: `%APPDATA%\Mika`.
- Журнал: `%LOCALAPPDATA%\Mika\logs\mika.log`.
- Ключи и токены: «Диспетчер учётных данных», записи `Mika`.

## Чего ещё нет

- Модель Live2D: нужны лицензия Cubism SDK и сама модель.
- Подпись установщика сертификатом.

## Что не проверено вживую

- Настоящий микрофон и активационная фраза.
- Перетаскивание мышью и второй монитор.
- Telegram с настоящим ботом.
- Радиомодули, яркость, медиаклавиши.
- Установка обновления целиком.

Подробности — в [решениях проекта](https://github.com/Artem936c/Mika/tree/main/docs/decisions).
