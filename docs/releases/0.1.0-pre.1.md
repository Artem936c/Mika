# Мика 0.1.0-pre.1

Первый пре-релиз. Текстовый помощник: чат в островке вверху экрана, действия в Windows, проверка риска перед каждым действием.

## Установка

1. Запустить `Mika_0.1.0-pre.1_x64-setup.exe`. Права администратора не нужны, приложение ставится для текущего пользователя.
2. Островок появится вверху основного монитора. Щелчок по нему или Ctrl+Alt+M открывает чат.
3. При первом запуске откроются настройки провайдера: тип, адрес, модель, ключ. Кнопка «Проверить» покажет задержку первого ответа.

Пример для RouterAI: тип «OpenAI-совместимый», адрес `https://routerai.ru/api/v1`, модель `mistralai/mistral-nemo` (самая дешёвая с вызовом инструментов) или `qwen/qwen3.6-35b-a3b` (умнее, тоже дешёвая).

## Что умеет

- Отвечает потоком, шутит, рассказывает анекдоты, играет в словесные игры.
- 28 инструментов: время, громкость, блокировка, сон, перезагрузка, выключение, буфер обмена, состояние системы, процессы, запуск и закрытие программ, переключение окон, поиск, чтение, запись, перемещение файлов, удаление в корзину, команды PowerShell и cmd, ссылки в браузере, поиск в интернете, чтение страниц, погода, заметки, удалённый рабочий стол.
- Перед каждым действием карточка: что будет сделано, точная цель, уровень риска. Ответ кнопкой или в чате: «да», «разреши всегда», «нет». Действия высокого риска нельзя разрешить навсегда. Без ответа за 60 секунд действие отклоняется.
- Вкладка «Разрешения»: постоянные правила с отзывом и журнал решений.
- Поиск, чтение страниц и погода выключены, пока их не включить на вкладке «Инструменты».
- Значок в области уведомлений, автозапуск (по умолчанию выключен), удаление всех данных на вкладке «Общие».

## Где данные

- Настройки, история, заметки, правила: `%APPDATA%\Mika`.
- Журнал: `%LOCALAPPDATA%\Mika\logs\mika.log`.
- Ключи провайдеров: «Диспетчер учётных данных» Windows, записи `Mika`.

## Чего ещё нет

Голос и активационная фраза, 2D-аватар, управление кнопками в чужих окнах, напоминания и таймеры, память о пользователе, MCP, Telegram, обновления. Это эпики 5–10 плана.

## Известные ограничения

- Сборка не подписана: Windows SmartScreen предупредит при установке.
- Перенос островка на другой монитор и режим обычного окна ещё не сделаны: островок всегда на основном мониторе.
- Самые дешёвые модели иногда отвечают по памяти вместо вызова инструмента.
- Окна с правами администратора недоступны.

## Проверено

На Windows Server 2025 через удалённый рабочий стол, 1920 × 1080, провайдер RouterAI с `mistral-nemo`.
