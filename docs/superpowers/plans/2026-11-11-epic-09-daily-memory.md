# Эпик 9 «Быт и память»: пошаговый план

**Цель.** Возможности умной колонки и память о пользователе: напоминания, дела, курсы, новости, медиа, факты о пользователе, поиск по прошлым разговорам.

**Дизайн:** разделы 5, 7; [решение 0009](../../decisions/0009-core-features.md).

## Общие правила

- Каждый инструмент регистрируется в реестре и имеет тест с подменой системного вызова.
- Сетевые инструменты работают только при включённых интернет-инструментах.
- Ядро не зависит от Tauri и Windows: планировщик живёт в `mika-core`, уведомление показывает `mika-gui`.

## Задачи

### 1. Хранилище

- `storage.rs`: миграции `reminders`, `todos`, `facts`, `commands`. `archive_messages(conversation)` переименовывает разговор в `archive-<время>`.
- Тест: архив не попадает в `load_messages("main")`.

### 2. Планировщик

- `mika-core/src/schedule.rs`: `ReminderStore` (добавить, список, отменить, взять просроченные, сдвинуть повтор), `Repeat`, `next_due`.
- `spawn_scheduler(store, bus, on_task)`: раз в секунду берёт просроченные, публикует `Event::ReminderFired { id, text, kind, late_s }`, для вида `task` вызывает `on_task(text)`.
- Тесты: повтор каждый день сдвигает срок на сутки вперёд от текущего времени; просроченное срабатывает один раз; отменённое не срабатывает.

### 3. Инструменты напоминаний и дел

- `mika-tools/src/reminders.rs`: `reminder_set` (текст, `in_minutes` или `at`, `repeat`, `kind`), `reminder_list`, `reminder_cancel`.
- `mika-tools/src/todos.rs`: `todo_add` (текст, дата), `todo_list` (дата, выполненные), `todo_done`, `todo_remove`.
- Разбор времени: `HH:MM` (сегодня или завтра, если уже прошло), `YYYY-MM-DD HH:MM`.

### 4. Память

- `mika-core/src/memory.rs`: `FactStore`, `prompt_block(budget)`.
- `agent.rs`: системный промпт дополняется блоком фактов перед каждым запросом.
- `mika-tools/src/memory.rs`: `memory_save`, `memory_search`, `memory_forget`, `history_search`.
- Тест: удалённый факт не попадает в промпт.

### 5. Курсы, новости, медиа, радио, яркость, архивы

- `web.rs`: `get_rates` (ЦБ РФ), `get_news` (RSS).
- `media.rs`: `media_control`, `now_playing`; интерфейс `Media` в `sys.rs`, реализация в `win/media.rs`.
- `system.rs`: `radio` (Wi-Fi, Bluetooth), `brightness`; интерфейсы `Radios`, реализация в `win/radio.rs`. Яркость идёт через `Runner`.
- `files.rs`: `archive_create`, `archive_extract` через `tar.exe`.

### 6. Интерфейс

- События `ReminderFired` в чате и в облачке аватара, уведомление Windows.
- Страница «Память»: факты, удаление, очистка архива.
- Страница «Островок»: город, скрывать в играх, монитор.
- Покой: ближайший таймер и погода.

## Готово, когда

- «Напомни через десять минут выключить чайник» срабатывает уведомлением.
- Напоминание переживает перезапуск.
- Факт из прошлого разговора используется в новом.
- Удалённый факт больше не используется.
