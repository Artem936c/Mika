# Эпик 4 «Инструменты, часть 1» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Основные действия в Windows из текстового чата: система, программы, файлы, командная строка, интернет, заметки, удалёнка, погода.

**Architecture:** Крейт `mika-tools`. Каждый инструмент реализует `mika_core::tools::Tool` и обращается к системе только через узкий типаж (`Launcher`, `Volume`, `Power`, `Windows`, `Clipboard`, `Runner`, `Http`, `Trash`, `RdpSource`). Настоящие реализации живут в `mika-tools/src/win/`, подделки в тестах. `register_all(&mut ToolRegistry, ToolEnv)` регистрирует всё сразу. Риск считает `assess`, классификаторы из эпика 3 уточняют его.

**Tech Stack:** эпики 1–3, `windows 0.62`, `winreg`, `arboard`, `sysinfo`, `reqwest`.

**Spec:** [дизайн](../specs/2026-11-10-mika-assistant-design.md), раздел 7.

## Global Constraints

- Уровни риска по разделу 7 дизайна. Классификатор может только поднять уровень.
- Интернет-инструменты (`web_search`, `fetch_page`, `get_weather`) работают только при `tools.web_enabled = true`. По умолчанию выключено. Открытие ссылки в браузере сеть приложения не использует и работает всегда.
- Удаление идёт только в корзину. Удаления мимо корзины в эпике 4 нет.
- Командная строка: лимит времени по умолчанию 60 с, максимум 600 с. Отмена убивает процесс. Вывод обрезается до 16 000 символов.
- На машине разработки высокорисковые инструменты не запускаются по-настоящему: только тесты с подделкой.

## Мои решения

- **Погода — Open-Meteo.** Без ключа, геокодер и прогноз в одном сервисе.
- **Поиск в интернете — HTML-версия DuckDuckGo.** Без ключа. Если разметка сменится, инструмент вернёт понятную ошибку.
- **Архивы, Wi-Fi, Bluetooth, яркость и раскладка окон по экрану** переносятся в эпик 8 и 9. Для MVP они не нужны, а Wi-Fi, Bluetooth и яркость нельзя проверить на машине разработки (виртуальная машина без этих устройств). Записано в решении 0006.
- **Запуск программы** ищет имя в словаре синонимов («блокнот» → `notepad`), затем в ярлыках меню «Пуск». Найденное имя — шаблон правила.
- **Карточка погоды в чате** откладывается до эпика 6. В MVP погода приходит текстом.

## Review Focus

1. Модель попросила `open_path` для `setup.exe`. Ожидание: высокий риск, это запуск программы. Тест в задаче 3.
2. Команда висит дольше лимита. Ожидание: процесс убит, LLM получает «превышено время». Тест в задаче 4.
3. Город не найден геокодером. Ожидание: понятная ошибка, не паника. Тест в задаче 5.
4. Интернет выключен в настройках. Ожидание: инструмент отвечает, как включить, и не ходит в сеть. Тест в задаче 5.
5. Путь с `..` уводит в `C:\Windows`. Ожидание: риск записи высокий. Тест в задаче 3.

### Task 1: Каркас крейта и системные типажи

**Files:** `crates/mika-tools/{Cargo.toml, src/lib.rs, src/sys.rs, src/win.rs, src/win/*.rs}`.

```rust
// sys.rs
pub trait Launcher: Send + Sync { fn open(&self, target: &str, args: Option<&str>) -> Result<(), String>; }
pub trait Volume: Send + Sync { fn get(&self) -> Result<(u8, bool), String>; fn set(&self, level: u8) -> Result<(), String>; fn set_mute(&self, mute: bool) -> Result<(), String>; }
pub enum PowerAction { Lock, Sleep, Restart, Shutdown, Logoff }
pub trait Power: Send + Sync { fn act(&self, action: PowerAction) -> Result<(), String>; }
pub struct WindowInfo { pub id: u64, pub title: String, pub process: String }
pub trait Windows: Send + Sync { fn list(&self) -> Vec<WindowInfo>; fn focus(&self, id: u64) -> Result<(), String>; fn close(&self, id: u64) -> Result<(), String>; }
pub trait Clipboard: Send + Sync { fn get(&self) -> Result<String, String>; fn set(&self, text: &str) -> Result<(), String>; }
pub trait Trash: Send + Sync { fn trash(&self, path: &Path) -> Result<(), String>; }
pub trait RdpSource: Send + Sync { fn saved_hosts(&self) -> Vec<String>; fn rdp_files(&self) -> Vec<PathBuf>; }
#[async_trait] pub trait Runner: Send + Sync { async fn run(&self, program: &str, args: &[String], timeout: Duration, cancel: CancellationToken) -> Result<RunOutput, String>; }
pub struct RunOutput { pub code: Option<i32>, pub stdout: String, pub stderr: String, pub timed_out: bool }
#[async_trait] pub trait Http: Send + Sync { async fn get(&self, url: &str) -> Result<String, String>; }
pub struct ToolEnv { launcher, volume, power, windows, clipboard, trash, rdp, runner, http: Arc<dyn ..>, db: Arc<Db>, web_enabled: Arc<AtomicBool>, user_profile: String }
impl ToolEnv { pub fn windows(db: Arc<Db>, web_enabled: Arc<AtomicBool>) -> Self; }
pub fn register_all(reg: &mut ToolRegistry, env: &ToolEnv);
```
