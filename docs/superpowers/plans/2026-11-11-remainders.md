# Остатки эпиков 5, 6, 9, 10: пошаговый план

**Цель.** Закрыть пункты, отложенные в решениях 0009 и 0010, которые не ждут пробных сборок и решений пользователя.

**Дизайн:** разделы 6, 10; [решение 0011](../../decisions/0011-window-mode-and-remainders.md).

## Задачи

### 1. Режим обычного окна (6.4)

- `config.rs`: `window.rect` — положение и размер окна в режиме `window`.
- `window.rs`: `enter_window_mode`, `enter_island_mode`, флаг `WINDOWED` для потока пропуска щелчков.
- `bridge.rs`: `set_window_mode`; `get_ui_settings` отдаёт режим.
- Интерфейс: в режиме окна чат и настройки занимают всё окно, кнопка «Открепить» становится «Закрепить».
- Крестик окна возвращает островок, а не закрывает приложение.
- Тест: сохранённое место за пределами мониторов не используется.

### 2. Серверы MCP по HTTP (10.1)

- `mcp.rs`: транспорт HTTP рядом со stdio: POST JSON-RPC, ответ JSON или SSE, заголовок `Mcp-Session-Id`.
- `config.rs`: `url` у сервера.
- Тесты на поддельном сервере: ответ JSON, ответ SSE, сеанс передаётся дальше.

### 3. Задержки этапов (5.10) и выбор микрофона (5.1)

- `Event::Timing { stage, ms }`: распознавание, первое слово модели, первый звук.
- Строка под ответом в чате.
- `voice.input_device`, список устройств на странице «Голос».

### 4. Плеер в покое (9.7)

- `idle_info` отдаёт текущий трек; островок показывает его вместо имени, пока трек играет.

## Не входит

Активационная фраза, Live2D, обновления, подпись, перетаскивание островка.
