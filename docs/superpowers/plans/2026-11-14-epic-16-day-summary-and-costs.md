# Эпик 16. Итог дня и расходы

Дата: 2026-11-14.

## Цель

Вечером Мика коротко рассказывает, что было за день, и предлагает план на завтра. Каждый платный вызов провайдера считается: единицы, а где известна цена — деньги. Есть бюджет на день и на месяц с предупреждениями, страница «Расходы» и два инструмента для вопросов «как прошёл день» и «сколько потрачено». Подробности и правила в решении 0028.

## Подход

Вечерний итог не становится вторым ритуалом: это вторая половина утренней сводки, с теми же условиями и тем же циклом. Факты собирает код из базы, текст пишет один короткий запрос `llm::complete` без инструментов. Чего в базе не было (фокус, сделанные дела, напоминания, задачи) — пишет новый журнал дня.

Расходы считаются в адаптерах `mika-providers`: каждый адаптер отдаёт запись в общий приёмник ядра. Подписи `build_provider` и `Live` не меняются, поэтому вызовы из других эпиков считаются сами. Цена берётся из ответа провайдера, затем из его списка моделей, затем из настроек; без цены показываются единицы.

Новый код лежит в новых файлах. В общих файлах правки короткие и только добавляют: одна миграция, одна строка в `Config`, три поля в `BriefingConfig`, два инструмента в группе `daily`.

Работа делится на две части, которые идут параллельно: ядро, провайдеры и инструменты; приложение и интерфейс. Общие имена и поля закреплены заранее.

## Шаги

1. **Ядро: хранение** (`mika-core/src/storage.rs`). Одна новая запись в `MIGRATIONS`: таблицы `cost_usage`, `cost_prices`, `cost_alerts`, `day_log`.
2. **Ядро: журнал дня** (`mika-core/src/daylog.rs`).
   - `DayLog`: добавить запись, прочитать день, забыть старше 60 дней.
   - `run_recorder`: слушает шину и пишет сработавшие напоминания и законченные задачи.
3. **Ядро: расходы** (`mika-core/src/costs.rs` и папка `costs/`).
   - Запись о платном вызове `PaidCall`, виды `CostKind`.
   - Цены `UnitPrices` и расчёт стоимости вызова.
   - `Costs`: запись вызова, цены из списка и из настроек, пересчёт вызовов без цены, отчёт за период, состояние бюджета, пороги 80% и 100%.
   - Общий приёмник: `install`, `installed`, `record`.
   - Настройки `CostsConfig` и `ManualPrice`; строка `costs` в `Config`.
   - `BriefingConfig`: `evening_enabled`, `evening_time`, `evening_last_date`, `evening_due`.
4. **Провайдеры: счётчики** (`mika-providers/src/metering.rs` и правки адаптеров).
   - OpenAI-совместимый адаптер: `stream_options.include_usage` только при включённом учёте, разбор `usage`, повтор без поля при отказе 400 или 422; первая ошибка, если отказан и повтор.
   - Anthropic: `usage` из `message_start` и `message_delta`.
   - Эмбеддинги, картинки, синтез, распознавание: запись после удачного ответа.
   - Распознавание: тело удачного ответа разбирается целиком, без обрезки до 300 знаков.
   - Запрос `/generation` для озвучки без цены по знакам.
   - Цены: `UnitPrices` из списка моделей; обновление списка по запросу ядра. Ключ для списка цен — ключ раздела, который пользуется адресом; адрес основной модели получает только её ключ.
5. **Инструменты** (`mika-tools`).
   - `day.rs`: сбор фактов дня, текст для модели, текст без модели, карточка, инструмент `day_summary`. Названия извне — одна строка до 120 знаков; ответ модели — до 600 знаков; блок «Завтра» для разговора — с пометкой «данные».
   - `costs.rs`: инструмент `cost_report`.
   - `focus.rs`: начало сессии и запись в журнал при её конце.
   - `todos.rs`: запись в журнал, когда дело стало сделанным.
   - `lib.rs`: два инструмента в группе `daily`, подсказки, счётчик в тесте.
6. **Связка** (`mika-gui/src/app.rs`, `mika-gui/src/rhythm.rs`, `mika-cli`). Создать `Costs`, поставить приёмник, запустить обновление цен и запись журнала, передать журнал фокусу, показать предупреждение о бюджете репликой. Во время фокуса предупреждение ждёт в своём месте, не среди уведомлений, и после фокуса его показывает цикл ритма. `mika-cli` печатает предупреждение в терминале.
7. **Приложение: вечерний итог** (`mika-gui/src/everyday.rs`, новый `dayend.rs`). Проверка в цикле сводки, сбор фактов, запрос к модели, реплика, заметка в разговор; команды настроек.
8. **Приложение: расходы** (новый `mika-gui/src/costs.rs`, `main.rs`). Команды страницы: показать, включить, бюджет, своя цена, обновить цены, стереть.
9. **Интерфейс** (`frontend`).
   - Раздел «Расходы»: сегодня и месяц, полосы бюджета, по видам, по моделям, свои цены.
   - Вечерний итог на странице «Инструменты» под утренней сводкой.
   - Карточки `day_summary` и `cost_report` в чате.
   - Ключи в `ru.json`, сценарии в `dev/mock.ts`.
10. **Документы.** Решение 0028, дизайн §5, §7, §10, §11, строка в плане по эпикам.

## Проверка

- Модульные тесты:
  - стоимость вызова по каждому виду цены; цена из ответа важнее списка, список важнее своей цены;
  - вызов без цены хранится отдельно и получает цену, когда она появилась; уже посчитанное не меняется;
  - запрос без `usage` считается как запрос без единиц; распознавание неизвестной длины — так же, и цена, пришедшая позже, не делает его оплаченным по нулю;
  - день из одних бесплатных вызовов называется бесплатным, а не «цена неизвестна»;
  - после перезапуска вызов к модели без сохранённой цены сразу просит список цен;
  - деньги без валюты входят в бюджет, только когда валюта провайдера основной модели неизвестна и пользователь сохранил свою;
  - пороги бюджета: 80% и 100% по одному разу, сразу 100% без 80%, новый день, перезапуск, смена лимита;
  - расходы в чужой валюте не входят в бюджет;
  - имя сервера из адреса: без пути, параметров и имени пользователя;
  - разбор `usage` OpenAI, OpenRouter, Anthropic, распознавания; длина WAV;
  - `UnitPrices` из списка RouterAI: чат, озвучка по знакам, Gemini TTS, распознавание по секундам, картинка;
  - журнал дня: запись, чтение дня, срок хранения; фокус и дело пишут в него;
  - факты дня: выключенный учёт времени не читается; текст без пустых строк; план на завтра только для сегодня;
  - оба инструмента: низкий риск, отказ на неизвестный период;
  - `evening_due` и старый `config.toml` без новых полей.
- Тест с локальным сервером: поток с `usage` в последнем куске записывается один раз; оборванный поток записывается как запрос без единиц; отказ на `stream_options` повторяется без поля, и отказ, который поле не называет, тоже; запрос, отказанный по другой причине, возвращает первую ошибку; Ollama по адресу не из домашней сети не считается бесплатной.
- Интерфейс: тесты разбора карточек, `npm run check`, макеты `?mock=settings&page=costs`, `?mock=costs`, `?mock=day`.
- `cargo fmt`, `cargo clippy -D warnings`, `cargo test --workspace`.
- С настоящим ключом, вручную: сумма за день на странице «Расходы» сходится со статистикой RouterAI; предупреждение на 80% при маленьком лимите; «Показать сейчас» у вечернего итога.

## Что не делаем

- Не блокируем вызовы при исчерпанном бюджете.
- Не пересчитываем валюты.
- Не шлём вечерний итог в Telegram по расписанию.
- Не меняем утреннюю сводку.
- Не добавляем новых событий шины и новых полей в `Shared`.
- Не считаем токены по длине текста, когда провайдер их не сообщил.
