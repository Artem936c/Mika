# Выразительная речь для Fish Audio Drama 3

Дата: 2026-11-13.

## Цель

С моделью `fish-audio/drama-3` Мика размечает ответы ремарками `[...]` и парными тегами `<whisper>…</whisper>`, голос их исполняет, а в чате и везде, где текст читают, разметки нет. Подробности и правила в решении 0026.

## Подход

Разметку отделяет ядро. Поток ответа после фильтра рассуждений делится на показ (без разметки) и речь (с разметкой). Речь едет в несериализуемом поле `spoken` событий `AssistantDelta` и `AssistantText`. Озвучка берёт `spoken`, если оно есть, иначе `text`. Пока режим выключен, `spoken` всегда `None`, и всё работает как раньше.

## Шаги

1. **Ядро: модуль разметки** (`mika-core/src/marks.rs`).
   - Потоковый `MarkFilter`: `push(&str)` и `finish()` возвращают `MarkPiece { shown, spoken, directions }`.
   - `strip_marks(&str) -> String` для целого текста.
   - Разбор целого текста на куски `Token`: текст, ремарка, открытый тег, закрытый тег. Его использует озвучка.
   - Список 14 тегов.
   - Правила ремарки и тега из решения 0026.
   - Отложенный пробел: нет двойных пробелов, нет пробела перед знаком препинания на месте ремарки, нет пробелов в начале.
2. **Ядро: настройки** (`mika-core/src/config.rs`).
   - `VoiceConfig::tts_expressive`, по умолчанию `false`.
   - `expressive_model(model) -> bool`: в имени есть `drama`, регистр любой.
   - `VoiceConfig::expressive()`: все четыре условия из решения.
3. **Ядро: события и агент** (`events.rs`, `agent.rs`).
   - Поле `#[serde(skip)] spoken: Option<String>` в `AssistantDelta` и `AssistantText`.
   - `Agent::set_marks_switch`: замыкание, которое читает настройку при каждом шаге.
   - В `one_step` один снимок переключателя решает и подсказку, и фильтр.
   - Цепочка такая: `ThoughtFilter`, затем `TagFilter`, который пропускает ремарки и вырезает из обеих копий остальные метки эмоций, затем `MarkFilter`, затем `route` и `say`. Метки эмоций берутся и из вырезанных ремарок.
   - Дельта с пустым показом не публикуется: её речь копится до следующей дельты. Разметка после последних слов шага уходит пустой дельтой, а полная речь всё равно уходит в `AssistantText.spoken`.
   - Перед каждым следующим шагом, пока режим включён, публикуется `StepStarted`: озвучка договаривает текст до него.
   - Вызовы, написанные текстом, разбираются по тексту с разметкой; из текстов для людей в аргументах инструментов разметка вырезается.
   - История хранит чистый текст.
   - Константа подсказки `MARKS_HINT` лежит в ядре.
   - Все остальные места с этими событиями переходят на `{ text, .. }` и `spoken: None`.
4. **Озвучка** (`mika-audio/src/speech.rs`, `win.rs`).
   - `Voice::speak_marked(marked, plain)`; по умолчанию вызывается `speak(plain)`. Обёртка пересказа его передаёт дальше.
   - `WindowsVoice`: провайдеру уходит разметка, голосу Windows — чистый текст.
   - Обычный `speak` отдаёт провайдеру текст со скобками `[ ]`, заменёнными на `( )`, и без `< >`. Слова модели без разметки идут через `speak_reply` и уходят провайдеру как раньше.
   - `clean_marked_for_speech`: очищает текст только между разметкой, держит теги закрытыми, выбрасывает пустые ремарки и пары тегов, а фразу из одной разметки возвращает пустой.
   - `SentenceSplitter` в режиме разметки не режет внутри ремарки или тега и переносит открытые теги и ремарку строки через границу фраз. Фраза из одной разметки присоединяется к следующей. Длина считается по видимому тексту.
   - `run_speaker` берёт `spoken` и считает порог пересказа по показу.
   - Пересказ получает флаг режима и текст с разметкой.
   - `fallback_brief` в этом режиме держит теги закрытыми.
5. **Приложение** (`mika-gui`).
   - Переключатель разметки для агента читает `config.voice.expressive()`.
   - Подсказка пересказа с разметкой.
   - Команда `set_expressive_speech(value)`.
   - Поля `tts_expressive` и `expressive_model` в `VoiceSettings`.
   - `save_speech_settings` возвращает `expressive_model` сохранённой модели.
   - «Проверить голос» с разметкой в этом режиме: окно отправляет фразу `voice.test_phrase_expressive`.
   - Команда регистрируется в `main.rs`.
6. **Живой тест** (`mika-providers`, по умолчанию не запускается). Синтез фразы с разметкой моделью `fish-audio/drama-3` по настройкам пользователя, затем распознавание. В распознанном не должно быть слов из разметки.
7. **Интерфейс** (`frontend`).
   - Переключатель в ветке провайдера раздела «Голос», подсказка, предупреждение о другой модели.
   - Ключи в `ru.json`.
   - Поля и параметр `&drama` в `dev/mock.ts`.
8. **Документы.** Решение 0026, дизайн §9, §10, §11, записка к выпуску 0.3.3.

## Проверка

`cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `npm --prefix frontend test`, `npm --prefix frontend run check`, `npm --prefix frontend run build`. Один запуск живого теста.

## Что не делаем

- Прямой API Fish Audio со своим ключом.
- Многоголосие и фонемы.
- Разметку в истории: модель видит её только в подсказке.
