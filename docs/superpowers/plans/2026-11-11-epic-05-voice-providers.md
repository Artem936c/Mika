# Эпик 5 «Голос» через провайдеров: пошаговый план

**Цель.** Сказать фразу в микрофон и услышать ответ голосом выбранного провайдера.

**Дизайн:** разделы 6, 8, 11; [решение 0010](../../decisions/0010-voice-providers.md).

## Общие правила

- Микрофон не открывается, пока `privacy.microphone_enabled` выключен.
- Ключ речи хранится в диспетчере учётных данных и не попадает в журнал и тексты ошибок.
- `mika-core` не знает про звук: в нём только интерфейсы и правило голосового подтверждения.

## Задачи

### 1. Ядро

- `llm.rs`: интерфейсы `SpeechToText` и `TextToSpeech`.
- `config.rs`: `voice.tts` (`windows` или `provider`), `tts_model`, `tts_voice`, `stt_model`, `stt_language`, `speech_base_url`; `SPEECH_SECRET_KEY`.
- `confirm.rs`: `voice_answer(text, assessment)`, `DecidedBy::Voice`.
- `session.rs`: `Origin::Voice`.
- Тесты: высокий риск подтверждается только названием действия; «отмена» отклоняет любой риск.

### 2. Провайдеры

- `mika-providers/src/speech.rs`: `Live::transcribe` (multipart), `Live::synthesize`, `audio_mime` по первым байтам, обёртка WAV для сырого PCM.
- Тесты на поддельном HTTP-сервере: поля формы, разбор ответа, ошибка 400 без ключа в тексте.

### 3. Звук

- `mika-audio/src/mic.rs`: `Vad` (порог от шума, тишина 1,1 с, предел 45 с, 7 с без речи), сведение в моно, пересчёт в 16 кГц, запись WAV. Захват через `cpal`.
- `mika-audio/src/win.rs`: очередь, где фраза приходит либо текстом для голоса Windows, либо готовым звуком от провайдера; при ошибке провайдера фраза читается голосом Windows.
- Тесты: конец речи по тишине, отмена без речи, щелчок не считается речью. Порядок фраз задаёт сама очередь: каждая фраза ждёт свой звук.

### 4. Приложение

- `voice_listen`, `voice_cancel`, `set_microphone_enabled`, `save_speech_settings`, `test_microphone`.
- Вторая горячая клавиша.
- Состояние «Слушаю» на время записи.

### 5. Интерфейс

- Переключатель «Микрофон» и кнопка в поле ввода.
- Страница «Голос»: движок озвучки, модели, голос, язык, проверка микрофона.

## Готово, когда

- Фраза в микрофон приводит к ответу голосом.
- При выключенном «Микрофоне» запись не начинается.
- Высокий риск голосом подтверждается только названием действия.
- Синтезированная провайдером фраза распознаётся провайдером обратно в тот же текст.
