# Эпик 13. Помощник на каждый день

Дата: 2026-11-13. Выпуск: 0.3.0.

Пользователь выбрал пункты 1–8 и 10 из списка идей. Локальные модели для ответов не рассматриваются. Часть пунктов уже была сделана раньше: перебивание по имени (эпик 12), громкость, музыка, процессы и разбор файлов (эпики 4 и 9). По ним эпик добавляет только то, чего не хватало.

## Шаги

### 1. Перебивание голосом

- Vosk слушает не только имя, но и слова «стоп», «хватит», «замолчи», «помолчи», «тихо», «достаточно».
- Такое слово действует только пока Мика говорит. Она замолкает и заканчивает голосовой разговор, но не начинает слушать.
- Если слово есть в её собственной реплике, это эхо, его не слушаем.
- Распознаватель Windows этих слов не знает: его грамматика держит только имя, иначе ложные срабатывания.
- Тест: `Listener` на сгенерированном звуке не проверить. Проверяются разбор слова и решение в `on_wake` через `wake::heard_kind`.

### 2. Музыка тише, пока Мика слушает и говорит

- Громкость других программ (сеансы звука Windows, кроме своего процесса) опускается до 30% от их уровня, пока состояние «слушаю» или «говорю».
- Возврат через 1,5 секунды после конца, чтобы при повторном слушании звук не прыгал.
- Настройка `voice.duck_media` (включена по умолчанию).

### 3. Громкость отдельной программы

- `Volume` получает `apps()` и `set_app()` через `IAudioSessionManager2`.
- Инструмент `app_volume`: список, уровень, тише, громче, выключить и включить звук программы. Риск низкий.

### 4. Действие с выделенным текстом

- Горячая клавиша Ctrl+Alt+X (запасная Ctrl+Shift+X).
- Мика копирует выделенное через Ctrl+C и сразу возвращает старое содержимое буфера.
- Окно Мики показывает карточку с текстом и кнопками: перевести, объяснить, исправить ошибки, перефразировать, короче.
- Ответ можно вставить на место выделенного кнопкой «Вставить». Это действие пользователя, а не модели. Окно из слепой зоны не трогается ни при копировании, ни при вставке.

### 5. «Почему тормозит»

- Инструмент `system_health`: два замера процессора с паузой, самые тяжёлые процессы, память, место на дисках, батарея, время без перезагрузки.
- В конце выводы простыми словами. Риск низкий.

### 6. Уведомления

- Читаются из базы уведомлений Windows (`wpndatabase.db`, только чтение) раз в 2 секунды. API `UserNotificationListener` для программ без пакета недоступен.
- Включаются отдельным переключателем `privacy.notifications_enabled` (выключен по умолчанию).
- Не читаются уведомления программ из слепой зоны (банк, оплата, пароли) и уведомления с кодами подтверждения.
- Новое уведомление попадает в разговор заметкой, так что «ответь ему» понятно модели. По настройке Мика читает его вслух.
- Пропускаются собственные уведомления Мики и уведомления старше запуска.

### 7. Утренняя сводка

- Настройка `briefing`: включена, время. Сводка запускается после назначенного времени, когда за компьютером кто-то есть (ввод за последние 2 минуты), один раз в день.
- Сводка — задача агенту: погода (город острова), дела и напоминания на сегодня, курсы, коротко новости.

### 8. Клик по картинке

- `Screen` получает `ocr_words()` с рамками слов.
- Инструмент `screen_click(target, window)`: сначала ищет надпись распознаванием текста на этом компьютере. Если её нет, спрашивает модель со зрением по сетке с номерами клеток, затем по сетке внутри выбранной клетки.
- Нужен «Экран». Риск средний, как у `ui_click`. Слепая зона проверяется до снимка.

### 9. Автоответ в чате

- Инструмент `chat_watch(contact, action, note, minutes)`: следить за перепиской с человеком, перестать, список. Риск низкий: сам он ничего не отправляет.
- Новое уведомление от этого человека становится задачей агенту: составить ответ и отправить через `messenger_send`.
- Каждая отправка подтверждается пользователем (высокий риск, навсегда не разрешается). Слежка кончается через `minutes` (по умолчанию 60, не больше 240).
- Работает только при включённых уведомлениях.

### 10. Файлы

- `search_text`: поиск текста внутри файлов папки (текстовые форматы, до 2 МБ на файл, до 3000 файлов).
- `disk_usage`: что занимает место в папке — самые большие папки и файлы.
- Риск обоих низкий: только чтение в профиле пользователя.
