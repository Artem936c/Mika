# Эпик 10 «Расширения»: пошаговый план

**Цель.** Возможности растут без изменения кода: серверы MCP, свои команды, задачи по расписанию, картинки, команды из Telegram.

**Дизайн:** раздел 7; [решение 0009](../../decisions/0009-core-features.md).

## Задачи

### 1. Изменяемый реестр

- `agent.rs`: реестр лежит в `RwLock<Arc<ToolRegistry>>`, `Agent::set_registry`. Подключение сервера MCP пересобирает реестр без перезапуска.

### 2. Клиент MCP

- `mika-providers/src/mcp.rs`: запуск процесса, JSON-RPC построчно, `initialize`, `tools/list`, `tools/call`, предел ожидания 60 секунд.
- `McpTool` реализует `Tool`: средний риск, имя `mcp_<сервер>_<инструмент>`, шаблон правила — имя инструмента.
- `config.rs`: `[[mcp.servers]] name, command, args, enabled`.
- Тест: поддельный сервер на PowerShell не нужен — транспорт абстрагирован, тест работает через пару каналов в памяти.

### 3. Свои команды

- `mika-core/src/commands.rs`: `CommandStore` (сохранить, список, удалить, найти по сообщению). Сравнение без регистра и знаков.
- `session.rs`: сообщение, равное имени команды, заменяется её текстом.
- Инструменты `command_save`, `command_list`, `command_delete`.

### 4. Задачи по расписанию

- Напоминание вида `task` (эпик 9, задача 2). Планировщик передаёт текст в `Session::submit`.

### 5. Картинки

- `mika-providers/src/image.rs`: `ImageProvider`, адаптер `/images/generations` (ответ `b64_json` или `url`).
- `config.rs`: `[image] base_url, model`; ключ `image.api_key`, по умолчанию ключ LLM.
- Инструмент `generate_image`: сохраняет PNG в `Изображения\Mika`, отдаёт карточку с путём.

### 6. Telegram

- `mika-providers/src/telegram.rs`: `getUpdates` длинным опросом, `sendMessage`, кнопки `inline_keyboard`, `answerCallbackQuery`.
- Мост: сообщение от разрешённого пользователя уходит в `Session::submit`; `AssistantText` и `ConfirmRequested` уходят в Telegram, пока последний запрос пришёл оттуда.
- `config.rs`: `[telegram] enabled, user_id`; токен `telegram.bot_token`.
- Тест: сообщение от чужого идентификатора отклоняется; «всегда» для высокого риска не предлагается.

### 7. Интерфейс

- Страница «Расширения»: серверы MCP, свои команды, расписание, Telegram, картинки.

## Готово, когда

- Подключённый сервер MCP даёт инструменты, и они спрашивают разрешение.
- Команда «рабочий режим» открывает заданные программы.
- Задача по расписанию выполняется при закрытом окне чата.
- Команда из Telegram от чужого аккаунта отклоняется.
