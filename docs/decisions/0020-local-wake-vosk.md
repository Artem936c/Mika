# 0020. Активационная фраза на локальной модели Vosk

Дата: 2026-11-12. Статус: принято.

## Вопрос

Пользователь попросил, чтобы имя слышала локальная модель и реагировала на любой голос без обучения, как колонка с Алисой. После имени речь по-прежнему распознаёт провайдер. Подход разрешено взять у jarvis (Priler), код — нет.

Раньше имя слышал распознаватель Windows (решение 0012). Ему нужен русский речевой пакет Windows, и точность у него невысокая.

## Что рассматривали

- **Rustpotter.** Сравнивает звук с образцами фразы. Чтобы он слышал любой голос, нужны сотни записей имени разными людьми. Без них он узнаёт в основном голос того, кто записывал образцы.
- **Своя маленькая сеть, как у Алисы.** Колонку учили на огромном наборе записей слова. Для нас это значит синтезировать тысячи «Мика» разными голосами (платно) и обучить сеть. Это долго; имеет смысл, только если Vosk будет ошибаться.
- **Vosk** (подход jarvis). Распознаватель речи, обученный на тысячах русских голосов. Обучать ничего не нужно.

## Решение

1. **Движок — Vosk.** Модель `vosk-model-small-ru-0.22` (Apache 2.0) и `libvosk` 0.3.45 для Windows (Apache 2.0).
2. **Распознаётся вся речь, имя ищется целым словом.** Сначала распознаватель был ограничен списком фраз и `[unk]`. На проверке он с полной уверенностью принимал за «мику» слова «мама», «микрофон», «Михаил» и «мир» (18 ложных срабатываний из 20 фраз). Без ограничения он распознаёт фразы как есть, и «микроволновка» остаётся микроволновкой.
3. **Реакция по промежуточному результату.** Имя видно в частичном тексте через 0,3–0,5 с после того, как его сказали. Ждать паузы после имени не нужно. После срабатывания распознаватель сбрасывается и 1,5 с молчит, чтобы одна фраза не будила дважды.
4. **Своя привязка.** `mika-audio/src/vosk.rs` загружает `libvosk.dll` во время работы через `LoadLibraryExW` по полному пути, зависимости DLL берутся из той же папки. Без файлов приложение собирается и работает как раньше. Пути с кириллицей передаются в короткой форме 8.3.
5. **Скачивание — только по кнопке.** В разделе «Голос» есть кнопка «Скачать модель»: около 60 МБ с alphacephei.com и GitHub, на диске около 140 МБ. Оба архива сверяются с SHA-256, зашитыми в код. Распаковывает системный `tar.exe`, файлы для сборки (`libvosk.lib`, `vosk_api.h`) удаляются. Папка — `%LOCALAPPDATA%\Mika\vosk`. Кнопка «Удалить модель» останавливает слушателя и удаляет папку.
6. **Распознаватель Windows остаётся запасным**, пока модели нет.
7. **Имя должно быть в словаре модели.** Если слова нет, Мика пишет об этом в настройках и предлагает другое имя или удалить модель.

## Проверено

- Тест `mika-audio/tests/vosk_wake.rs` (отключён по умолчанию, нужна скачанная модель) подаёт в слушателя голоса Windows Irina и Pavel. Шесть фраз с именем («Мика», «Эй, Мика», «Мика, открой браузер»…) услышаны ровно по разу. Десять фраз без имени («Микроволновка опять сломалась», «Мама мыла раму», «Михаил пришёл домой», «Ника, иди сюда», «Микрофон работает»…) не разбудили ни разу. Итого 32 из 32.
- Модульные тесты: ответы Vosk и уверенность слов читаются, отсутствие библиотеки сообщается, имя считается только целым словом.
- С живым микрофоном не проверено: на машине разработки его нет.

## Что это меняет в дизайне

Раздел 2, таблица крейтов: `mika-audio` слушает имя через Vosk или распознаватель Windows. Раздел 11, «Голос»: активационная фраза на Vosk, распознаватель Windows запасной.
