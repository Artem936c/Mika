# 0014. Агент для ПК: задачи в несколько шагов, браузер, файлы пакетом

Дата: 2026-11-12. Статус: принято.

## Вопрос

Пользователь выбрал целью следующего этапа агента для ПК: сложные задачи в несколько шагов, браузер, файлы, проверка результата. План: [2026-11-12-epic-12-pc-agent.md](../superpowers/plans/2026-11-12-epic-12-pc-agent.md).

## Решение

### Задачи в несколько шагов

1. **План — инструменты `task_plan` и `task_step`.** Модель составляет план до 20 шагов и отмечает шаги: начат, сделан, не вышел, не нужен. Оба инструмента низкого риска и меняют только доску задачи в чате. Как и все инструменты, они идут через политику рисков: при решении «проверять всё» модель спросит о них один раз, и «разреши всегда» снимает вопрос.
2. **Лимит шагов.** Без плана — прежние 8 запросов к модели на сообщение. С планом — 40.
3. **Напоминание.** Если модель замолчала, а в плане остались незакрытые шаги, ядро дважды напоминает ей служебной заметкой, какие шаги открыты. Дешёвые модели иначе бросают план на середине.
4. **Конец задачи.** Сообщение закончилось: недоделанный шаг становится «не вышло: не закончен», после «Стоп» — «не вышло: остановлено». Шаги, до которых не дошли, становятся «пропущен». Задача удалась, только если все шаги закрыты, без неудач и без остановки.
5. **Интерфейс.** Событие `task_updated` несёт задачу целиком. Над полем ввода видна панель: название, «3 из 7», полоса, шаги со значками, кнопка «Стоп». Строки `task_plan` и `task_step` в ленту чата не попадают.
6. **Системная подсказка.** Задачу больше чем из трёх действий — сначала план. Перед шагом отметить его, после действия проверить результат и только потом отметить «сделано». После двух неудач подряд — спросить пользователя.

### Браузер Мики

7. **Отдельный профиль.** Edge (или Chrome, если Edge нет) запускается с `--user-data-dir=<данные Мики>\browser` и `--remote-debugging-port=0`. Порт выбирает сам браузер и пишет его в `DevToolsActivePort` внутри профиля, слушает он только `127.0.0.1`. Новый запуск Мики подхватывает уже открытый браузер по этому файлу. Браузер и профиль пользователя не трогаются.
8. **Протокол отладки (CDP)** через WebSocket, крейт `tokio-tungstenite` без TLS.
   - Снимок страницы — скрипт, который нумерует видимые ссылки, кнопки, поля и списки. Значения полей пароля он не читает.
   - Нажатие — событие мыши в центр элемента.
   - Ввод — фокус, выделение старого текста, `Input.insertText`, по желанию Enter.
9. **Инструменты**, группа «Браузер Мики»:

   | Инструмент | Что делает | Риск |
   |---|---|---|
   | `browser_open` | открыть адрес; нужен переключатель «Интернет» | низкий |
   | `browser_read` | прочитать страницу заново | низкий |
   | `browser_scroll` | прокрутить страницу | низкий |
   | `browser_click` | нажать элемент | средний |
   | `browser_type` | ввести текст | средний |

   Разрешение «всегда» действует на один сайт.
10. **Слепая зона в браузере** (`is_blind_url` рядом с `is_blind_title`). Страница с полем пароля, адрес или заголовок с признаками входа, банка, оплаты, кошелька. Такую страницу не читают и не трогают: модель получает только отказ. Открыть адрес входа тоже нельзя. Вход на сайты в профиле Мики пользователь делает сам.

### Файлы пакетом

11. **`list_folder`** — содержимое папки: размер, дата, отбор по расширению, вложенные папки. Низкий риск по пути.
12. **`file_batch`** — до 200 действий `move`, `copy`, `rename`, `mkdir`, `trash` одним подтверждением.
    - Карточка показывает число действий каждого вида и первые 15 строк.
    - Уровень риска — наибольший из уровней путей, с корзиной — высокий.
    - «Разреши всегда» действует только на точно такой же список.
    - Занятое имя получает « (2)», папка в `to` значит «внутрь». Перенос на другой диск — копирование и удаление источника.
    - Отчёт: «Сделано N из M», затем список неудач.

## Проверено

- Тесты:
  - доска задачи;
  - задача из 6 шагов проходит дальше лимита в 8 запросов;
  - напоминание о незакрытых шагах;
  - остановка;
  - слепая зона по адресу и полю пароля;
  - уровни риска инструментов браузера;
  - пакет файлов на временной папке: перенос, копирование, конфликт имён, отсутствующий источник, корзина;
  - панель задачи и скрытие служебных строк в чате.
- Ручной тест с настоящим Edge без окна: страница, ввод, нажатие, страница с паролем. Запуск: `cargo test -p mika-tools live_browser -- --ignored`.
- Вживую через `mika-cli` на `openai/gpt-oss-20b`:
  - разбор тестовой папки из 7 файлов по трём подпапкам с проверкой через `list_folder`;
  - поиск ответа на DuckDuckGo;
  - Википедия — открыть, нажать поиск, ввести «Канберра», перейти, прочитать год основания.
- Предпросмотр панели задачи: `?mock=task` и `?mock=task&done`.

## Что заметили на дешёвой модели

- Она часто выбирает короткий путь: адрес с запросом вместо ввода в поле, PowerShell вместо `file_batch`, английские имена папок вместо русских.
- План она составляет не всегда.
- Без напоминания она бросала план на середине.
