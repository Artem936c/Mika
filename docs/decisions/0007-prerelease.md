# 0007. Пре-релиз 0.1.0-pre.1

Дата: 2026-11-11. Статус: принято.

## Вопрос

Пользователь попросил довести MVP до пре-релиза и проверить его на машине разработки с самыми дешёвыми моделями. Что нужно, чтобы приложение можно было поставить и пользоваться им без терминала?

## Решение

Пре-релиз — это MVP из решения 0006 плюс часть эпиков 6 и 11, без которых им неудобно пользоваться:

1. **Установщик NSIS** для текущего пользователя, без прав администратора. MSI не собирается: он не принимает версию с суффиксом `-pre.1`.
2. **Журнал в файл** `%LOCALAPPDATA%\Mika\logs\mika.log`. Файл больше 5 МБ переименовывается в `mika.old.log` при запуске. Ключи в журнал не попадают: в журнал пишутся только тексты ошибок, а они уже очищены от ключа.
3. **Один экземпляр.** Второй запуск сразу завершается.
4. **Значок в области уведомлений**: открыть чат, скрыть или показать островок, выход. Щелчок левой кнопкой открывает чат.
5. **Горячая клавиша Ctrl+Alt+M** (если занята — Ctrl+Shift+M) открывает чат и отдаёт окну фокус клавиатуры. Окно островка показывается без активации, поэтому без этого печатать в чат можно только после щелчка.
6. **Автозапуск** через раздел реестра `HKCU\...\Run`, по умолчанию выключен. Переключатель на вкладке «Общие».
7. **Удаление всех данных** с вкладки «Общие»: ключи в Credential Manager, автозапуск, папки `%APPDATA%\Mika` и `%LOCALAPPDATA%\Mika\logs`. Папку `%LOCALAPPDATA%\Mika` целиком удалять нельзя: в неё же установщик кладёт программу. Папки удаляются через две секунды после выхода, потому что база данных открыта, пока приложение работает.
8. **Первый запуск.** Если ключа нет и провайдер не Ollama, чат показывает подсказку, а щелчок по островку сразу открывает настройки провайдера.
9. **Настройка из терминала**: `mika-cli provider`, `mika-cli key` (ключ читается из стандартного ввода и уходит в Credential Manager), `mika-cli web`, `mika-cli status`, `mika-cli probe`.

## Найдено живой проверкой

Провайдер `https://routerai.ru/api/v1`, OpenAI-совместимый. Самые дешёвые модели с вызовом инструментов на 2026-11-10: `mistralai/mistral-nemo`, `openai/gpt-oss-20b`, `meta-llama/llama-3.1-8b-instruct`. Проверка шла на `mistral-nemo`, первый фрагмент ответа приходил через 1,0–1,9 с.

| Находка | Исправление |
|---|---|
| Инструмент времени отдавал день недели по-английски, модель перевела «Tuesday» как «среда» | День недели по-русски и часовой пояс в ответе инструмента |
| Модель говорила о пользователе в третьем лице и пересказывала служебные строки вроде «код выхода» | Правило в системном промпте |
| Щелчок по островку проходил насквозь: положение окна запоминалось до показа, а скрытое окно сообщает (0, 0) | Начальное положение берётся из расчёта размещения, кэш обновляется раз в секунду |
| Ctrl+Alt+Пробел уже занят приложением Claude | Клавиши Ctrl+Alt+M, запасной вариант Ctrl+Shift+M; в настройках видно, какие заняты на самом деле |
| Удаление всех данных стёрло бы установленную программу: она лежит в `%LOCALAPPDATA%\Mika` рядом с журналом | Удаляется только папка `logs`; тест `wipe_never_touches_the_install_folder` |
| `cargo build` без признака `tauri/custom-protocol` грузит интерфейс с `localhost:5173` | Отладочная проверка окна собирается с этим признаком; `cargo tauri build` включает его сам |

Качество самой дешёвой модели заметно: она иногда отвечает по памяти вместо поиска и путает «сегодня» и «завтра» в прогнозе. Для повседневной работы лучше `qwen/qwen3.6-35b-a3b` или модель уровня выше; её можно выбрать в настройках.
