# 0006. Границы MVP (веха В1)

Дата: 2026-11-10. Статус: принято.

## Вопрос

Пользователь попросил довести проект до MVP. Что входит в MVP и какие решения при этом приняты без пробных сборок?

## Решение

MVP — это веха В1 из плана: эпики 1–4. В чате островка Мика отвечает через выбранного провайдера, выполняет действия в Windows и спрашивает разрешение на каждое действие.

Пробные сборки 0.2–0.5 (аватар, голос, UI Automation, лицензии) не нужны для В1. Они остаются впереди и проводятся перед эпиками 5, 7 и 8.

## Что сделано иначе, чем в плане или дизайне

1. **Ollama через OpenAI-совместимый адрес.** Ollama отдаёт `/v1/chat/completions` с потоком и вызовами инструментов, поэтому отдельный адаптер не нужен. Тип провайдера `ollama` — это адаптер OpenAI с адресом `http://localhost:11434/v1` и без ключа.
2. **Чат 600 × 500 без аватара.** Это размер «без аватара» из раздела 10 дизайна. С аватаром в эпике 7 он станет 860 × 500.
3. **Настройки внутри чата.** Вкладки «Провайдер», «Разрешения», «Инструменты» открываются кнопкой в шапке чата. Отдельное окно настроек появится в эпике 6.
4. **Интернет-инструменты выключены по умолчанию.** Поиск, чтение страниц и погода включаются в настройках. Это следует общему правилу «сеть только после явного включения». Открытие ссылки в браузере работает всегда: сеть использует браузер, а не приложение.
5. **Погода — Open-Meteo, поиск — HTML-версия DuckDuckGo.** Оба без ключа.
6. **Неизвестная команда оболочки — высокий риск.** Средний риск только у команд из списка чтения. Поэтому «разрешать всегда» доступно для `Get-Process`, но не для произвольной программы.
7. **Шаблон правила задаёт инструмент** (поле `scope`): `*`, нормализованная команда, имя программы, адрес сайта, путь.
8. **Фраза в чате во время вопроса** считается ответом, если это «да», «разреши всегда», «нет» или их синонимы. Остальной текст не уходит в LLM: Мика просит сначала ответить на вопрос.
9. **«Разрешать всегда» недоступно, если в шаблоне правила есть `*`**, кроме шаблона `*` целиком. Шаблон строится из аргументов, и путь `Documents\*` превратился бы в правило на всю папку.
10. **В LLM уходит только последняя часть разговора**, до 40 000 символов, с обрезкой перед репликой пользователя. Кнопка «Новый разговор» в шапке чата стирает историю.
11. **Вызовы .NET (`::`), методов объектов (`.Delete()`) и запуск скрипта через точку** классификатор считает высоким риском.

## Перенесено из эпика 4

| Пункт | Куда | Почему |
|---|---|---|
| Wi-Fi, Bluetooth, яркость | эпик 9 | Нельзя проверить на машине разработки: виртуальная машина без этих устройств |
| Раскладка окон по экрану | эпик 8 | Ближе к управлению окнами |
| Архивы | эпик 9 | Не нужны для сценариев В1 |
| Карточка погоды в чате | эпик 6 | В MVP погода приходит текстом |

## Не проверено

- Живые провайдеры. Ключей на машине разработки нет. Адаптеры проверены на поддельном HTTP-сервере, включая поток, вызовы инструментов, ошибку 401 и обрыв посреди ответа.
- Громкость на настоящем устройстве. В отключённом удалённом сеансе нет устройства вывода звука, инструмент честно вернул ошибку.
- Внешний вид окна островка на рабочем столе. Удалённый сеанс был отключён, снимки экрана недоступны. Интерфейс проверен в браузере с поддельным мостом Tauri (`npm --prefix frontend run dev`, адрес `/?mock=chat`).
- Перезагрузка, выключение, сон, блокировка, завершение процессов, удаление в корзину. На машине разработки они не запускались: только тесты с подделкой и карточка высокого риска в терминальном клиенте.
