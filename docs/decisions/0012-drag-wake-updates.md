# 0012. Перетаскивание, задний план, активационная фраза, первый запуск, обновления

Дата: 2026-11-11. Статус: принято.

## Вопрос

Пользователь попросил:

1. Обойтись без стандартной рамки Windows.
2. Перетаскивать островок на второй монитор и менять режим окна перетаскиванием.
3. Уводить приложение назад, когда другая программа открыта на весь экран, и выводить вперёд, когда его зовут голосом или клавишами.
4. Доделать остальной функционал по плану.

## Решение

### Окно

1. **Рамки Windows нет ни в одном режиме.** Обычное окно рисует свою шапку и скруглённый край. Размер меняется за края и углы страницы: они запускают системное изменение размера.
2. **Перетаскивание.** Островок тянется за любое место, кроме кнопок. Нажатие без движения по-прежнему открывает чат. Открытый чат тянется за шапку и за колонку аватара, настройки — за левую панель. Двойной щелчок по шапке обычного окна разворачивает его на весь экран.
3. **Что значит бросок** — решает Rust по положению курсора и окна:
   - островок брошен у верхнего края монитора (верх островка не ниже 110 логических пикселей) — прилипает к верхнему краю этого монитора, монитор запоминается;
   - островок брошен ниже — становится обычным окном прежнего размера под курсором;
   - обычное окно брошено так, что курсор у самого верхнего края (12 логических пикселей) — снова островок на этом мониторе;
   - в остальных случаях окно остаётся там, где его бросили.

   Изменение размера за край броском не считается.
4. **Задний план.** Каждые 0,7 с проверяется, что впереди. Если это игра, презентация или другая программа, развёрнутая или растянутая на весь монитор островка, островок и аватар снимают «поверх всех окон» и уходят вниз по порядку окон. Сами окна не закрываются.
5. **Вызов наверх:** Ctrl+Alt+M, Ctrl+Alt+K, активационная фраза, кнопка голосового ввода. После вызова она остаётся впереди не меньше 10 секунд и дальше, пока отвечает или пока её окно в фокусе. Вопрос о действии выводит её вперёд и без вызова. Ответ, начатый не по вызову (задача по расписанию), назад не мешает.
6. Обычное окно не держится поверх других, поэтому назад не уходит: оно просто перекрывается.

### Голос

7. **Активационная фраза — распознаватель, встроенный в Windows** (`Windows.Media.SpeechRecognition`, список фраз). Он работает на этом компьютере, звук никуда не уходит. Решение 0010 откладывало фразу до пробной сборки 0.3, потому что облачное распознавание для неё не годится; встроенный распознаватель снимает это возражение. Нужно, чтобы в Windows было установлено распознавание речи для языка.
8. **Фразы:** «Мика», «эй, Мика», «привет, Мика», «Мика, слушай», «слушай, Мика». Имя берётся из настройки, принимаются результаты с высокой и средней уверенностью. Фраза работает, только пока включены «Микрофон» и переключатель «Откликаться на…» на странице «Голос».
9. **Перебивание (5.7).** Фраза, сказанная, пока она говорит, обрывает речь и начинает запись.
10. **Своё эхо.** Пока она говорит и её текущий ответ содержит её имя, фраза пропускается: иначе её голос из динамиков будил бы её саму.

### Первый запуск (11.3)

11. **Экран из двух шагов.** Первый — провайдер. Второй — интернет, экран, микрофон, активационная фраза и проверка микрофона; всё выключено, пока не включишь. Профиль, где ключ уже сохранён, экран не показывает. Ключ хранится в диспетчере учётных данных один на всех пользователей Windows, поэтому новый профиль на той же машине тоже считается настроенным.

### Обновления (11.4)

12. **Файл с описанием версии** по адресу https, который вводит пользователь: версия, адрес установщика `.exe` по https, SHA-256, что нового.
13. **Проверка** — при запуске (можно выключить) и по кнопке. **Скачивание и установка** — только по кнопке со вторым подтверждением.
14. **Установщик запускается**, только если совпала контрольная сумма. Он ставится тихо после выхода приложения, затем приложение запускается снова.
15. **Адрес пуст по умолчанию.** Сервера выпусков у проекта нет, поэтому без адреса ничего не проверяется.

### Расширения

16. **Токен для сервера MCP по адресу.** Хранится в диспетчере учётных данных под именем `mcp.<сервер>.token`, уходит заголовком `Authorization: Bearer`. В тексты ошибок не попадает. Удаляется вместе с сервером и при «Удалить все данные».

## Не сделано: нужно решение пользователя

- **Live2D (7.1–7.3, 7.7–7.9).** Cubism SDK распространяется только после принятия лицензии на сайте Live2D, и к нему нужна модель. Принять лицензию за пользователя и выбрать модель (7.12) я не могу. Аватар остаётся рисунком SVG.
- **Сила и затухание эмоций (7.4).** Нужны только параметрам Live2D.
- **Подпись сборок (11.7).** Нужен сертификат подписи кода.
- **Сервер выпусков для обновлений.** Нужно место, где лежат установщик и файл описания.

## Проверено

- Тесты: что значит бросок на одном и двух мониторах с разным масштабом; когда она уходит назад и возвращается; правила эха; фразы для имени; язык распознавателя; сравнение версий; проверка файла обновлений и контрольной суммы; токен MCP в заголовке и его отсутствие в тексте ошибок.
- В окне приложения через отладочный порт: активационная фраза включается; без устройства записи на странице «Голос» видно «микрофон недоступен». Адрес обновлений без https отклоняется. Первый запуск завершается командой.
- В предпросмотре: экран первого запуска, обычное окно с восемью краями для размера и кнопкой «Закрепить», кнопка «Установить 0.3.0», переключатель «Откликаться на «Мика»».

## Не проверено

- **Перетаскивание и изменение размера мышью, второй монитор, уход назад за развёрнутую программу.** Управление мышью и окнами для проверки пользователь не разрешил. Монитор у машины разработки один.
- **Активационная фраза вживую.** На машине нет микрофона.
- **Установка обновления целиком.** Сервера выпусков нет.
