## Сборка

```
npm --prefix frontend install
npm --prefix frontend run build
cargo test --workspace
npm --prefix frontend test
cd crates/mika-gui && cargo tauri build
```

Нужны Rust из `rust-toolchain.toml`, Node 22+, Windows 10/11 с WebView2. Предпросмотр интерфейса без Tauri: `npm --prefix frontend run dev`, затем `http://localhost:5173/?mock=chat` (сценарии в `frontend/src/dev/mock.ts`).

## Состояние

- Сделано: эпики 1–4 (текстовый помощник с проверкой риска), пре-релиз 0.1.0-pre.1, интерфейс по макету (эпик 6 без режимов окна), ядро эмоций и SVG-аватар (часть эпика 7). Все тесты проходят.
- Голос (эпик 5) пользователь перенёс в конец.
- Отложено: режимы окна (6.4), поведение в играх (6.5), Live2D (эпик 7), пробные сборки 0.2–0.5.
- Новый интерфейс проверен в предпросмотре и через отладочный порт WebView2, но не настоящими щелчками мыши.

## Ключи

Ключей провайдеров в архиве нет. Они хранятся в диспетчере учётных данных Windows (запись `Mika`). Ключ вводится в настройках приложения или командой `mika-cli key openai` (читает ключ из стандартного ввода).
