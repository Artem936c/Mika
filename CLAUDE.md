# Мика: правила проекта

Живой ИИ-помощник для Windows на Rust и Tauri 2. «Мика» — рабочее имя.

## Где что лежит

- Дизайн: `docs/superpowers/specs/2026-11-10-mika-assistant-design.md`. Это источник истины о том, что строим.
- План по эпикам: `docs/superpowers/plans/2026-11-10-roadmap.md`.
- Пошаговые планы эпиков: `docs/superpowers/plans/`.
- Решения по итогам пробных сборок: `docs/decisions/`.
- Макет интерфейса: `docs/design/island-mockup.html`.
- Тексты интерфейса: `frontend/src/locales/ru.json`. Их читает и Rust (меню значка).
- Пробные сборки: `spikes/`. Код оттуда в продукт не переносится.

## Порядок работы

- Перед началом эпика пишется его пошаговый план.
- Решение, которое меняет дизайн, записывается в `docs/decisions/` и вносится в дизайн в том же изменении.
- Коммит и push делаются только по просьбе пользователя.

## Правила, которые нельзя нарушать

- Каждый инструмент регистрируется в реестре с уровнем риска и выполняется только через политику рисков.
- Действия высокого риска нельзя разрешить навсегда.
- Ключи провайдеров хранятся в Windows Credential Manager. В `config.toml`, журнал и текст ошибок они не попадают.
- Микрофон и просмотр экрана выключены, пока пользователь явно их не включил.
- Код Priler/jarvis не копируется: его лицензия накладывает условия на производный код. Берётся только подход к организации кода.
- Персонаж оригинальный. Чужих персонажей не копируем.

## Стиль кода

- Рабочее пространство Cargo. Версии зависимостей задаются один раз в `[workspace.dependencies]`, крейты пишут `dep.workspace = true`.
- Редакция Rust 2021, стандартный `rustfmt` без своих настроек.
- Модули в виде `foo.rs` рядом с папкой `foo/`. Файлов `mod.rs` нет.
- `mika-core` не зависит от Tauri и платформенных крейтов, кроме `keyring`.
- Журнал через `log`, блокировки через `parking_lot`, настройки в TOML, ошибки через `thiserror`.
- Интерфейс на Svelte только рисует состояние и отправляет команды. Логика живёт в Rust.
- Тексты интерфейса на русском и вынесены из кода в файлы локализации (начиная с эпика 6).
- Код, идентификаторы и сообщения коммитов на английском. Документы на русском.

## Крейты

| Крейт | Назначение |
|---|---|
| `mika-core` | Шина событий, состояние, настройки, секреты, цикл агента, политика, эмоции, память |
| `mika-providers` | Адаптеры LLM, распознавания, синтеза, картинок |
| `mika-audio` | Микрофон, активационная фраза, воспроизведение |
| `mika-tools` | Инструменты Windows |
| `mika-cli` | Терминальный клиент для отладки ядра |
| `mika-gui` | Приложение Tauri 2 |

Интерфейс лежит в `frontend/`.

## Команды

```
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all --check
cargo run -p mika-cli
npm --prefix frontend test
npm --prefix frontend run check
npm --prefix frontend run dev   # предпросмотр: http://localhost:5173/?mock=chat, сценарии в frontend/src/dev/mock.ts
cargo tauri dev            # из crates/mika-gui
```

Интерфейс собирается раньше команд Cargo для `mika-gui`: при компиляции нужна папка `frontend/dist`.
